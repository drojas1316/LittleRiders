# Little Riders

## Descripción General
Little Riders es una aplicación web orientada a mejorar la experiencia de transporte escolar para estudiantes y padres de familia. El sistema busca conectar de forma segura a los padres con los conductores y la administración, facilitando la gestión de rutas, el seguimiento básico del recorrido y la comunicación entre los actores del servicio.

## Características Principales
- Registro e inicio de sesión de usuarios (padres de familia).
- Gestión de estudiantes, permitiendo asociar a los hijos con sus rutas correspondientes.
- Simulación de GPS y seguimiento básico de rutas en tiempo real.
- Panel de comunicación simple entre padres y la administración del servicio.

## Guía de Uso
### Flujo para el Padre
1. El padre se registra en la aplicación y crea su cuenta.
2. Inicia sesión con sus credenciales.
3. Agrega a su hijo dentro del sistema.
4. Asocia al estudiante con la ruta o servicio correspondiente.
5. Puede consultar la información relacionada con el recorrido y mantener comunicación con la administración.
